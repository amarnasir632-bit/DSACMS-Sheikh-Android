# تطبيق طلبات التواصل

تطبيق Android مستقل للشيخ، مبني بـJava وواجهات Android Views/XML. هذا المجلد لا يغيّر الموقع أو الـBackend.

## الوضع الحالي

- أُنشئت واجهات تسجيل الدخول، قائمة الطلبات وتصفيتها، تفاصيل الطلب، وحالة الإشعارات.
- أُضيفت خدمة FCM وقناة الإشعارات وطلب صلاحية Android 13+، ويؤدي ضغط الإشعار إلى فتح التطبيق ومعه معرّف الطلب.
- عند الربط، ينبغي أن يحمل إشعار الخادم نصًا عامًا بلا رقم هاتف، وأن يرسل معرّف الطلب في حمولة البيانات لفتح تفاصيله.
- لا يوجد اتصال بخادم الموقع في هذه النسخة؛ لذلك لا تُعرض بيانات طلبات ولا تُفعّل أزرار تغيير الحالة أو التواصل قبل إضافة API مصادق عليه.
- لا يحتوي المشروع على بيانات Firebase أو أسرار أو أرقام هواتف.

## فتح المشروع

افتح هذا المجلد في Android Studio مع Android SDK API 36 وJDK 17. يعتمد البناء على Android Gradle Plugin 8.13.2 وGradle 8.13. لا يتوفر Android SDK أو Gradle في بيئة الإنشاء الحالية، لذلك لم يُنتج APK هنا.

## إعداد Firebase لاحقًا

1. أنشئ تطبيق Android في Firebase بالمعرّف `com.dsacms.sheikhrequests`.
2. نزّل `google-services.json` وضعه في `app/`. هذا الملف مستثنى من Git.
3. أعد مزامنة Gradle؛ سيُطبّق Google Services plugin تلقائيًا عند وجود الملف.
4. اختبر صلاحية الإشعارات على الهاتف. استقبال FCM يتطلب جهازًا عليه Google Play Services أو محاكيًا بصورة Google APIs.

إرسال رمز FCM إلى الخادم، تسجيل دخول الشيخ، وجلب الطلبات وتحديث حالاتها مؤجلة إلى مرحلة تصميم واجهة API مع الموقع. لا تضع مفتاح إرسال FCM أو Service Account داخل التطبيق.

## البناء

بعد تثبيت Android Studio وSDK المناسب وإضافة ملف Firebase:

```bash
gradle assembleDebug
gradle assembleRelease
```

لإنتاج APK موقّع للنشر، أضف إعداد توقيع محلي آمن ولا تضع keystore أو كلمات مروره في المستودع.
